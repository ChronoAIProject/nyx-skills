# Google 表格：怎么读

「本店设置」里：「连接」是 Google 连接的名字，「表格」是表格文件的 ID。所有工作表都在这一个文件里。

## 工具

只用 `…__sheets_get_values`，前缀是连接名。你没有写的工具。

## 表长什么样

「费用」页和「待付」页的列一样：

A 编号｜B 记账时间｜C 日期｜D 商家｜E 金额｜F 币种｜G GST｜H 类别｜I 单据类型｜J 发票号｜K 到期日｜L 付款状态｜M 已付金额｜N 付款日期｜O 状态｜P 备注｜Q 原件｜R 未付金额｜S 算出的到期日｜T 距到期天数

「费用」页第 1 行是表头，第 2 行是示例行，记录从第 3 行开始。编号是写在 A 列的固定数字，不等于行号：认一条记录只看 A 列。

## 先看「设置」页的数对不对

每轮第一次读表时，读 `'设置'!B3:B4` 和 `'费用'!A3`。A3 是数字，而 B3 是 0 或 B4 不大于 A3：台账的公式是旧写法、坏了（0.6 及更早建的台账，「待付」也数不到新记的发票）。这时不报「没有待付」，回复老板：「台账的公式要修，现在的待付清单不准。请对 NyxBot 说：修一下台账公式。」

## 读还没付清的发票和贷项

读 `'待付'!A2:T500`。这一页是表格公式从「费用」里筛出来的：单据类型是发票或贷项通知单、付款状态不是已付、状态不是作废，按到期日从早到晚排好了。

- I 列是「发票」的是待付发票，是「贷项通知单」的是没抵掉的贷项。
- **R 未付金额、S 算出的到期日、T 距到期天数都是表格算好的，直接用，不自己再算。** T 小于 0 是已逾期，等于 0 是今天到期，1 到 3 是 3 天内，4 到 7 是 7 天内，再大是更晚。
- K 到期日是空的而 S 有值：这张的到期日是按默认账期推算的，要标「按默认账期」。
- S 是空的：归到「缺日期」。
- L 是「不清楚」的归到「不确定付没付」。
- 这一页是空的，就是没有待付。读出来有 `#REF!`、`#N/A`、`#ERROR!` 这类错误：照实说「待付页的公式坏了，请找 NyxBot 修」，不自己去读整张「费用」来代替。
- 正好读满 499 行：说明可能没读全，照实说。
- 日期读出来是五位数字（例如 46366）：这一页没设日期格式。到期判断只看 T 距到期天数，不受影响；回复里该写日期的地方写「到期日见表」，并加一句「待付页的日期格式没设，请找 NyxBot 修」。不要自己把数字换算成日期。

## 按编号读一张

老板说「把第 N 条付了」时：先在刚读到的「待付」里找 A 列等于 N 的行。不在那里，再读 `'费用'!A{N+2}:T{N+2}`；A 列等于 N 就是它（多半是已付或作废了，照实说）。A 列不等于 N：说「第 N 条不在待付里，表里的位置也对不上，请找台账与对账专员核对」，不起草。

## 读某个商家以往的记录

1. 读 `'设置'!B3` 拿到记录数 n，最后一行是 n + 2。
2. 读最后 600 行的 `'费用'!A{起}:P{n+2}`，每次不超过 200 行，分三次读。按归一后的商家名自己挑。

这里没有按条件搜索，只看得到最近 600 条。更早付过款的供应商会被当成首次付款，提示时写「最近 600 条记录里没有付过」。

## 复核账单：读这家以往的记录

复核大额账单时（做法在 `references/bill-review.md`）用。照上面「读某个商家以往的记录」读最后 600 行的 `'费用'!A{起}:P{n+2}`，按归一后的 D 商家挑出这家的行，剔掉 O 状态是「作废」的和 I 单据类型是「贷项通知单」的。用到的列：A 编号、C 日期、D 商家、E 金额、F 币种、G GST、I 单据类型、J 发票号、L 付款状态、M 已付金额、O 状态、P 备注。

- **上一期**：C 日期早于这一张账单开票日期的行里，先挑 I 单据类型和这一张一样的最近一条（账单是发票就挑发票），没有再看收据和单据类型空着的；同一个月有几条，都列出来问老板。E 金额是含税总额。G 只记本地 GST、外币单据记 0：F 是本地币种、G 不是 0，E 减 G 才是税前；否则不算税前。账本里没有明细，也没有账期；Q 原件你读不了，要逐项比就请老板发上一期的账单。C 日期读出来是五位数字的：不自己换算，照实说「费用页的日期格式没设，请找 NyxBot 修」，这次请老板说上一期是哪张。
- **这一张在不在账本里**：J 发票号只留字母和数字、转大写后和账单上的相同；或者 E 金额相同、C 日期相差 5 天以内。在的话报 A 编号和 L 付款状态。
- 只看得到最近 600 条：找不到上一期时说「最近 600 条记录里没有这家以前的账单」。

## 读固定支出

读 `'固定支出'!A2:H200`：A 名称｜B 收款方｜C 金额｜D 币种｜E 每月几号｜F 付款方式｜G 状态｜H 类型。只看 G 是「启用」的行。这一页没有记录就跳过。

- H 是「法定缴费」或「订阅合同」：跳过不提，E 填了也不看。这两类由财务主管按到期日提醒。
- H 是空的或「固定支出」：照 E 每月几号提醒。H 是接入技能 0.9 起才建的，旧表没有这一列，读出来是空的，当固定支出。
- I 到 L 列（周期、到期日、提前几天、自动续费）是给财务主管用的，你不读。
