# 飞书多维表格：怎么读

「本店设置」里：「连接」是飞书机器人连接的名字，「表格」是多维表格的标识，「费用」表和「固定支出」表是数据表的 ID。

## 工具

只用这两个，前缀是连接名：`…__bitable_records_search`、`…__bitable_fields_list`。你没有写的工具。

- 搜索一律带筛选条件，用 `field_names` 只取要用的字段；有下一页就用 `page_token` 翻完。
- 单选字段用「等于」筛，一个值搜一次，不用「不等于」，免得漏掉或带出别的行。
- 日期条件接口不认时，改成只按别的条件筛，取回后自己按日期挑。

## 读还没付清的发票和贷项

在「费用」表搜四次，取回后剔掉状态是「作废」的：

1. 单据类型等于「发票」，付款状态等于「未付」；
2. 单据类型等于「发票」，付款状态等于「部分已付」；
3. 单据类型等于「发票」，付款状态等于「不清楚」；
4. 单据类型等于「贷项通知单」，付款状态等于「未付」。

未付金额和到期日表里没有现成的，照技能正文的规则自己算。

## 按编号读一张

老板说「把第 N 条付了」时：先在刚搜到的未付发票里找编号是 N 的。不在那里，再搜一次「编号」等于 N 的记录（按编号筛不了时，请老板说商家或发票号，按它搜回来再按编号挑）。找到的那一行已经是已付或作废，照实说，不起草。找不到就说「找不到第 N 条」。

## 读某个商家以往的记录

搜「商家」包含这个商家名里最有辨识度的一段的记录，取：编号、商家、日期、金额、发票号、单据类型、付款状态、状态、备注。取回后按归一后的商家名自己挑。

## 复核账单：读这家以往的记录

复核大额账单时（做法在 `references/bill-review.md`）用。搜「商家」包含这家供应商名里最有辨识度的一段的记录，取：编号、商家、日期、金额、币种、GST、发票号、单据类型、付款状态、已付金额、状态、备注。有下一页就翻完，取回后按归一后的商家名自己挑，剔掉状态是「作废」的和单据类型是「贷项通知单」的。

- **上一期**：日期早于这一张账单开票日期的记录里，先挑单据类型和这一张一样的最近一条（账单是发票就挑发票），没有再看收据和单据类型空着的；同一个月有几条，都列出来问老板。金额是含税总额。GST 只记本地 GST、外币单据记 0：币种是本地币种、GST 不是 0，金额减 GST 才是税前；否则不算税前。账本里没有明细，也没有账期；附件里的原件你读不了，要逐项比就请老板发上一期的账单。
- **这一张在不在账本里**：发票号只留字母和数字、转大写后和账单上的相同；或者金额相同、日期相差 5 天以内。在的话报编号和付款状态。

## 读固定支出

「本店设置」里「固定支出」表不是「无」时，搜状态等于「启用」的行，取全部字段。

- 「类型」是「法定缴费」或「订阅合同」：跳过不提，填了「每月几号」也不看。这两类由财务主管按到期日提醒。
- 「类型」是空的、是「固定支出」，或者表里没有「类型」这个字段（旧表）：照「每月几号」提醒。
- 「周期」「到期日」「提前几天」「自动续费」是给财务主管用的，待付清单不看。现金流预测要看，照 `references/cashflow.md`。
