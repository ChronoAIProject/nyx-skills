# 飞书多维表格：表和字段

老板选飞书多维表格时照这一份做（选 Google 表格的看 `build-gsheet.md`）。台账建在老板自己的飞书多维表格里，专员经 NyxID 读写，不另存一份。

这个连接的目录里只有读表、读字段、搜记录、新增记录、修改记录这几类操作，没有建表、建字段、删除。所以表由老板建，你只核对。

## 1. 老板要做的准备（只做一次）

1. 在飞书新建一个多维表格，名字随意，例如「某店 财务」。
2. 把第一张数据表改名为「费用」，照第 3 节建 17 个字段。字段名要一字不差，专员按名字读写。
3. 想让专员提醒房租、订阅这类没有发票的固定支出，再建一张「固定支出」表（7 个字段）。不建就不提醒。还想让财务主管提醒法定缴费（例如 CPF）和订阅、合同到期，在这张表里再加 5 个字段（第 3 节标「可选」的那几个）。
4. 把 NyxID 里那个飞书机器人应用加为这个多维表格的协作者，权限选可编辑。
5. 把多维表格的链接发给 NyxBot。

## 2. 怎么核对

1. 从链接取多维表格的标识：`/base/` 后面那一段。链接是知识库页面（`/wiki/`）时，先用连接的知识库节点工具换成多维表格的标识。
2. 用 `…__bitable_tables_list` 列出数据表，按名字找到「费用」和「固定支出」，记下各自的表 ID。找不到「费用」就停下告诉老板。
3. 对每张表用 `…__bitable_fields_list` 读出字段，照第 3 节逐个核对：字段在不在，类型存不存得下对应的内容，单选字段有没有要用的选项。「固定支出」缺标「可选」的那 5 个字段不算问题，只告诉老板：没有这几个字段，财务主管就不提醒法定缴费和续约；有了但类型或选项不对，照常列进问题里。
4. 一条消息列出全部问题，例如：「费用」缺字段：付款状态、已付金额；「状态」缺选项：作废。请老板补，补完重新核对一次。
5. 第 2、3 步任何一步报权限错误：把报错原文给老板，说明要把多维表格共享给机器人应用（可编辑），然后停下。不反复重试。
6. 核对阶段不往表里写任何测试记录。写入在第八步验收时测。

## 3. 字段

### 「费用」（必须有）

| 字段 | 类型 | 说明 |
|---|---|---|
| 商家 | 文本（主字段） | 单据上的商家名 |
| 编号 | 自动编号 | 回复里的「第 N 条」就是它 |
| 日期 | 日期 | 单据日期，不是记账日期 |
| 金额 | 数字，2 位小数 | 含税总额，一律正数 |
| 币种 | 单选：SGD、USD、CNY、HKD、其他 | 不换算；可以自己加币种 |
| GST | 数字，2 位小数 | 只填新加坡 GST，其余为 0 |
| 类别 | 单选：进货、房租、水电通讯、交通、餐饮、办公、软件订阅、差旅、其他 | 可以按本店情况增减，专员只用表里已有的选项；「其他」要留着 |
| 单据类型 | 单选：收据、发票、贷项通知单、退款 | |
| 发票号 | 文本 | 没有就空着 |
| 到期日 | 日期 | 发票上写的，或按账期推算的 |
| 付款状态 | 单选：已付、未付、部分已付、不清楚 | |
| 已付金额 | 数字，2 位小数 | 部分已付时填 |
| 付款日期 | 日期 | 老板确认已付的那一天 |
| 状态 | 单选：已记、待确认、作废 | |
| 备注 | 文本 | 待确认的原因、改动记录 |
| 收据 | 附件 | 原件 |
| 原消息 | 文本 | 可以不建。平台目前拿不到聊天消息的链接 |

已经在用旧版 11 个字段的表：加 6 个字段（单据类型、发票号、到期日、付款状态、已付金额、付款日期），「状态」加一个选项「作废」，「类别」按需要加选项。旧记录的新字段可以空着，专员不会回头去补：单据类型为空的一律当作收据。旧记录里有还没付的发票，请老板对台账与对账专员说「第 N 条是没付的发票」，由它补上，不然不会出现在待付清单里。

### 「固定支出」（可选，老板自己维护，专员只读）

| 字段 | 类型 | 说明 |
|---|---|---|
| 名称 | 文本（主字段） | 例如房租、宽带 |
| 收款方 | 文本 | |
| 金额 | 数字，2 位小数 | |
| 币种 | 单选 | 同「费用」 |
| 每月几号 | 数字 | 1 到 31。那个月没有这一天就按月底算 |
| 付款方式 | 单选：自动扣款、手动 | |
| 状态 | 单选：启用、停用 | |
| 类型 | 单选：固定支出、法定缴费、订阅合同 | 可选。空着就是固定支出 |
| 周期 | 单选：每月、每季、每年、一次 | 可选。法定缴费和订阅合同用 |
| 到期日 | 日期 | 可选。法定缴费填这一期的最后期限，订阅合同填到期或续费的那一天 |
| 提前几天 | 数字 | 可选。到期前几天开始提醒；空着时法定缴费 3 天，订阅合同 7 天 |
| 自动续费 | 单选：是、否 | 可选。订阅合同用 |

**怎么填。** 房租、宽带这类每月要付的钱：类型空着，填「每月几号」，后 4 个可选字段不用填，和以前一样。法定缴费和订阅合同：选类型，填周期和到期日，「每月几号」空着；金额填这一期大约多少，不知道可以空着。到期日过了，按周期的法定缴费和自动续费的订阅合同会自己往后算一期，不用每月改；办完一期想让它不再提，把到期日改成下一期；以后都不用提醒的，把状态改成停用。日期照写的提醒，周末和公共假期不顺延。新加坡常见的两项（CPF 和技能发展税每月填下一个月 14 日，外籍劳工税每月填下一个月 17 日）的官方出处，见仓库里 `pack/agents/finance-supervisor/README.md` 的「法定缴费和续约」。

已经在用 7 个字段的旧表：加上面 5 个字段就行，旧行的新字段空着，照旧当固定支出提醒。

## 4. 要告诉老板的两件事

- 新加坡要求业务记录至少保存 5 年。原始单据请自己另存一份，不要把聊天记录当成唯一的存放处。
- 这是一张旁路表，不是正式账。还没有接会计软件和银行流水，月底靠资料包交给会计。
