# 在 Google 表格里建台账

老板选 Google 表格时照这一份做。台账建在老板自己的 Google 账号里，专员经 NyxID 读写，不另存一份。

**实测记录（2026-11-12，在一张真的 Google 表格里）**：九处公式原样写入后，用 14 行编的记录核对，未付金额、推算到期日、距到期天数、「待付」的筛选和排序、「近期已付」、两块月度合计都和手算一致；把一张发票记为已付后，三页跟着更新；以等号开头的文字加了单引号后没有被当成公式。同一天补测：追加行落在最后一行后面，没有被公式列挤到表底；45 条格式、下拉、条件格式的请求一次设成功，设完「待付」里的日期显示成日期；文本格式的列里加单引号写入，内容没有被当成公式，单引号也没有存进去；把表排序（只排数据列，或连公式列整行排）之后，编号跟着行走，公式列照常重算，「待付」和「核对」不受影响。还没测到的只有一件：由 NyxBot 自己照这份说明来建。

两套坐标：`sheets_get_values`、`sheets_update_values` 用 A1 写法（`'费用'!A1`）；`sheets_batch_update_spreadsheet` 用数字 `sheetId` 和从 0 开始、末端不含的行列索引。颜色用 0 到 1 的 `red`、`green`、`blue`。公式照抄，一个字符都不改；公式里的函数名用英文。

## 1. 动手之前

1. 调用一次 `drive_list_files`（`q` 为 `trashed = false`，`pageSize` 1）。失败就一句话请老板授权 Google 账号，然后停下。
2. 查同名文件夹（`name = '{店名} 财务' and mimeType = 'application/vnd.google-apps.folder' and trashed = false`）。
   - 没有：往下建。
   - 有，而且是你在这次接入里刚建到一半的（这轮对话里有记录，或老板确认是刚才建的）：不重建。列出文件夹里的文件，读表格里已有的工作表，从缺的那一步接着做，最后照第 11 节整个核对一遍。
   - 有，但不是这次建的：停下来问老板复用还是另起一个名字，不要不问就往里写。

## 2. 文件夹和文件

1. `drive_create_file` 建文件夹 `{店名} 财务`（`mimeType` 为 `application/vnd.google-apps.folder`）。
2. 在它里面再建一个文件夹 `原件`。聊天里的原图存不进表，老板自己把原图传到这里。
3. 用 `sheets_create_spreadsheet` 建表格 `{店名} 财务台账`，**建的时候就把七张工作表、时区和语言一次带上**（请求里要带什么见第 3 节）。三个专员只认这一个表格 ID。
4. 这样建出来的表格在网盘根目录。用 `drive_update_file` 把它移进第 1 步的文件夹：`addParents` 填文件夹 ID，`removeParents` 填 `root`。

不要先用 `drive_create_file` 建一张空表格再去改结构：那样建出来只有一张工作表、时区是格林尼治时间，而改结构在平台里算破坏性操作，更容易被老板的审批规则拦下。

## 3. 结构（写在建表格的那一次请求里）

`sheets_create_spreadsheet` 的请求体带两部分：

- `properties`：`title` 为表格名，`timeZone` 为老板的时区，`locale` 为 `zh_CN`。时区不对，「距到期天数」会差一天。
- `sheets`：七张工作表，每张写 `properties` 里的 `sheetId`、`title` 和 `gridProperties`：
  - sheetId 0 `费用`：`frozenRowCount` 2，`rowCount` 5000，`columnCount` 20。默认只有 1000 行，不加行的话后面设格式会超出范围。
  - sheetId 1 `待付`、2 `核对`、3 `固定支出`、4 `设置`、6 `近期已付`：`frozenRowCount` 1。
  - sheetId 5 `使用说明`：不冻结。

建完读一次返回结果：七张工作表都在，时区是老板的时区，「费用」是 5000 行、冻结 2 行。

## 4. 设置（sheetId 4）

先写这一页，后面的公式要引用它。`sheets_update_values` 到 `'设置'!A1`，`USER_ENTERED`：

| 格 | 内容 |
|---|---|
| A1、B1、C1 | `项`、`值`、`说明` |
| A2、B2、C2 | `默认账期天数`、老板说的天数（默认 30）、`发票没写到期日时按几天算。改这里的同时要告诉 NyxBot，专员的设置也要改` |
| A3、B3、C3 | `记录数`、`=COUNTA('费用'!B3:B)`、`公式，不要改` |
| A4、B4、C4 | `下一个编号`、`=MAX('费用'!A3:A)+1`、`公式，不要改` |
| E1 | `类别选项` |
| E2 起 | 一格一个：进货、房租、水电通讯、交通、餐饮、办公、软件订阅、差旅、其他。老板说了自己的类别就按他的，「其他」要留着 |
| F1 | `币种选项` |
| F2 起 | 一格一个：SGD、USD、CNY、HKD、其他。老板第一步说的记账币种不在里面的，加在「其他」前面 |

老板以后要加类别或币种，在 E 列、F 列往下加一格就行。

## 5. 费用（sheetId 0）

第 1 行表头，第 2 行固定的示例行，记录从第 3 行开始。

`sheets_update_values` 到 `'费用'!A1`，`USER_ENTERED`。A1 到 Q1 是文字表头：

`编号, 记账时间, 日期, 商家, 金额, 币种, GST, 类别, 单据类型, 发票号, 到期日, 付款状态, 已付金额, 付款日期, 状态, 备注, 原件`

R1、S1、T1 不写文字，写下面的公式（公式自己会显示表头，并一直算到表尾）：

```
R1  ={"未付金额";"";ARRAYFORMULA(IF(B3:B="","",IF((I3:I="发票")+(I3:I="贷项通知单"),IFERROR(IF(E3:E="",0,E3:E)-IF(M3:M="",0,M3:M),""),0)))}
S1  ={"算出的到期日";"";ARRAYFORMULA(IF(B3:B="","",IF(K3:K<>"",K3:K,IF(C3:C="","",IFERROR(C3:C+'设置'!$B$2,"")))))}
T1  ={"距到期天数";"";ARRAYFORMULA(IF(S3:S="","",IFERROR(S3:S-TODAY(),"")))}
```

第 2 行是示例行：A2 写「示例」，B2 写「示例行：请勿删除。记录从第 3 行开始」，其他格留空。R2 以下到 T 列从不写入。

**编号是专员新增时写进 A 列的固定数字**，取自「设置」页 B4，不是按行号算的。这样老板即使排了序，编号也跟着那一行走，专员不会改错行。

为什么要示例行：追加记录时新行接在最后一行后面，并继承那一行的格式。没有示例行，第一条记录会继承表头的格式，下拉的范围也会被挤歪。为什么冻结 2 行：老板在界面里排序时，冻结的行不参与，示例行不会被排到中间去。

格式（一个 batch，范围都是第 2 到 5000 行）：

- 第 1 行套表头格式：深蓝底 (0.122, 0.22, 0.392)、白字、粗体、自动换行。第 2 行以下保持普通格式。
- 数字格式：A 列 `NUMBER` `0`；B 列 `DATE_TIME` `yyyy-mm-dd hh:mm`；C、K、N、S 列 `DATE` `yyyy-mm-dd`；E、G、M、R 列 `NUMBER` `0.00`；T 列 `NUMBER` `0`；D、J、P、Q 列 `TEXT`。
- 下拉（`setDataValidation`，`showCustomUi: true`，`strict: false`）：
  - F 币种：`ONE_OF_RANGE`，`='设置'!$F$2:$F$40`
  - H 类别：`ONE_OF_RANGE`，`='设置'!$E$2:$E$40`
  - I 单据类型：`ONE_OF_LIST` 收据、发票、贷项通知单、退款
  - L 付款状态：`ONE_OF_LIST` 已付、未付、部分已付、不清楚
  - O 状态：`ONE_OF_LIST` 已记、待确认、作废
- 条件格式（第 3 到 5000 行，自定义公式）：`=$O3="待确认"` 整行浅黄底 (1, 0.95, 0.75)；`=$O3="作废"` 整行灰字 (0.6, 0.6, 0.6)。
- 列宽默认 100；商家 180；备注 320。

## 6. 待付（sheetId 1）

专员读这一页拿待付清单，不用去翻整张「费用」。

`sheets_update_values` 到 `'待付'!A1`，`USER_ENTERED`。第 1 行 A 到 T 写文字表头，和「费用」的 20 列同名同顺序（R1 到 T1 写 `未付金额`、`算出的到期日`、`距到期天数`）。A2 写公式：

```
A2  =IFNA(SORT(FILTER('费用'!A3:T,('费用'!I3:I="发票")+('费用'!I3:I="贷项通知单"),'费用'!L3:L<>"已付",'费用'!L3:L<>"",'费用'!O3:O<>"作废"),19,TRUE),"")
```

筛出来的是：单据类型是发票或贷项通知单、付款状态不是已付、状态不是作废的行，按算出的到期日从早到晚。只有「一行都没筛到」才显示空白；公式本身坏了会显示错误，专员看得见。A2 以外不写任何东西。数字格式照「费用」的同名列设一遍，表头格式同上。

## 7. 近期已付（sheetId 6）

月底资料包要知道「月底时还没付、之后才付」的发票，从这一页找。第 1 行表头同「待付」。A2 写公式：

```
A2  =IFNA(SORT(FILTER('费用'!A3:T,'费用'!I3:I="发票",'费用'!N3:N<>"",'费用'!N3:N>=TODAY()-120),14,FALSE),"")
```

筛出来的是：付款日期在最近 120 天内的发票，最近付的排前面。数字格式照「费用」的同名列设一遍。

## 8. 核对（sheetId 2）

月底资料包和每周简报的合计从这里取，是表格算的，不是专员心算的。`USER_ENTERED` 写两个公式，其他格不写：

```
A1  =QUERY('费用'!C3:O,"select year(C), month(C)+1, F, I, sum(E), sum(G), count(C) where C is not null and (O is null or O <> '作废') group by year(C), month(C)+1, F, I label year(C) '年', month(C)+1 '月', F '币种', I '单据类型', sum(E) '金额合计', sum(G) 'GST 合计', count(C) '笔数'",0)
I1  =QUERY('费用'!C3:O,"select year(C), month(C)+1, F, H, sum(E), count(C) where C is not null and (O is null or O <> '作废') and (I is null or I = '收据' or I = '发票') group by year(C), month(C)+1, F, H label year(C) '年', month(C)+1 '月', F '币种', H '类别', sum(E) '金额合计', count(C) '笔数'",0)
```

左边一块（A 到 G）：每年每月、每个币种、每种单据类型的金额合计、GST 合计、笔数。右边一块（I 到 N）：每年每月、每个币种、每个类别的金额合计和笔数，只含收据和发票。没有日期的记录不属于任何一个月，这两块都不算它。

## 9. 固定支出（sheetId 3）

老板自己填，专员只读。第 1 行表头：`名称, 收款方, 金额, 币种, 每月几号, 付款方式, 状态`。下拉（第 2 到 200 行）：D 币种 `ONE_OF_RANGE` `='设置'!$F$2:$F$40`；F 付款方式 `ONE_OF_LIST` 自动扣款、手动；G 状态 `ONE_OF_LIST` 启用、停用。第一步老板说了房租这类固定支出的，替他填进来；没说就留空。币种照老板说的填；没说的填第一步的记账币种（默认 SGD），并在下一条消息里告诉老板「某某的币种按默认记成某某，不对请告诉我」。不要留空：2026-11-17 第一次全新安装时没问币种，两项固定支出的币种都空着。

## 10. 使用说明（sheetId 5）

A 列一行一条文字，A 列宽 900，自动换行：

- 「费用」是台账，只有台账与对账专员往里写。最右边三列是公式，不要改。
- 尽量不要给「费用」排序、删行、插行：专员是按「最后几百行就是最近记的」来查重和读数的。想换个顺序看，用「数据」里的筛选视图。记错的不要删，告诉专员作废。
- 「待付」「近期已付」「核对」三页是公式算出来的，只看不改。
- 「固定支出」自己填：房租、宽带这类每月固定要付、没有发票的钱。
- 「设置」里可以改默认账期，可以在类别、币种下面加选项。
- 原始单据：聊天里的图片存不进表。请把原图传到网盘的「原件」文件夹，文件名写上第几条；想在表里点开，就把链接贴到那一行的「原件」格。
- 记录要改：对台账与对账专员说「第 N 条金额改成…」；付了款说「第 N 条已付」。

## 11. 核对清单

建完逐项回读，不对就修好再往下；修不了在交付里写明。

- 用 `valueRenderOption=FORMULA` 读这九格，必须和上面逐字一致：`'费用'!R1`、`'费用'!S1`、`'费用'!T1`、`'待付'!A2`、`'近期已付'!A2`、`'核对'!A1`、`'核对'!I1`、`'设置'!B3`、`'设置'!B4`。
- 读 `'费用'!A1:T2`：表头 20 列，A1 是「编号」，A2 是「示例」，B2 是示例行说明。
- 读 `'设置'!A1:F12`：B2 是老板说的账期，B3 是 0，B4 是 1，E 列和 F 列的选项都在。
- 读 `'待付'!A1:T3`、`'近期已付'!A1:T3`：有表头，第 2 行以下是空的。
- 读 `'核对'!A1:N3`：还没有带日期的记录时，A1 和 I1 显示 `#VALUE!`，属正常（实测如此）。记进第一张带日期的单据后，必须变成表头加数字。
- 任何一处出现 `#NAME?`、`#ERROR!`、`#REF!`：公式抄错了，重写那一格再读。
- 把表格、文件夹的链接和表格 ID 记下来，交付时给老板，表格 ID 填进三个 Role。

验收时记进第一张发票后再读一次「待付」和「核对」：数字要对；「待付」里的日期要显示成 `2026-12-10` 这样的日期。显示成五位数字（例如 46366），说明第 5 到 7 节的日期格式没设上，补设。

## 12. 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| `Unable to parse range` | 工作表名不对或还没建 | 先做第 3 节 |
| 设格式时报超出表格范围 | 「费用」还是默认的 1000 行 | 第 3 节把行数设成 5000 |
| 「下一个编号」不是数字 | A 列里混进了文字 | 找出那一格改成数字 |
| 第一条记录变成深蓝底白字、没有下拉 | 没有示例行，记录插在了第 2 行 | 在第 2 行补示例行，第 2 行以下重设普通格式、下拉和条件格式 |
| 「待付」是空的，但「费用」里明明有未付发票 | 单据类型或付款状态写的不是下拉里的字 | 看那一行的 I 列和 L 列 |
| 到期日、距到期天数是空的 | 日期被写成了文字 | 日期写成 `yyyy-mm-dd`，前面不要带单引号 |
| 已经有记录了，「核对」还显示 `#VALUE!` | 「费用」的日期列里文字比日期多 | 同上，把日期改成真正的日期 |
| 「待付」「近期已付」里的日期是五位数字 | 这两页没设日期格式（公式搬过来的值不带格式） | 照第 6、7 节给日期列设格式；「费用」的 S 列同理 |
| 写入返回超时（例如 HTTP 524），当时有一条审批在等老板批 | 新账号默认每次写都要老板批，等批的这次调用约 100 秒就被掐断（2026-11-17 实测）；超时后这次写入作废，之后再批也不会发出去 | 告诉老板是在等他批、超时了。先回读确认没写进去（建文件夹的，按第 1 节查同名文件夹），再请他盯着、一分钟内批，重做一次 |
| 追加行、改表结构被拒，提示被审批规则拒绝 | 老板给这条连接设了「破坏性操作一律拒绝」；追加行、改单元格、改表结构在平台里都算破坏性 | 请老板去掉那条规则。删除和清空靠专员的操作范围挡 |
