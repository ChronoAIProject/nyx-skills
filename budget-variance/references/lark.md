# 飞书多维表格：预算差异怎么读（未实测）

「本店设置」里：「连接」是飞书机器人连接的名字，「表格」是多维表格的标识，「费用」表和「预算」表是数据表的 ID。

## 工具

只用这两个，前缀是连接名：`…__bitable_records_search`、`…__bitable_fields_list`。你没有写的工具。

- 用 `field_names` 只取要用的字段；有下一页就用 `page_token` 翻完。
- 单选字段用「等于」筛，一个值搜一次，不用「不等于」。

## 「预算」表

老板自己建、自己填，专员只读。字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| 月份 | 文本（主字段） | 写成 2026-08 |
| 类别 | 单选，选项和「费用」表的「类别」一样 | |
| 币种 | 单选，选项和「费用」表的「币种」一样 | |
| 预算金额 | 数字，2 位小数 | |

这张表一般只有几十行：搜索时不带筛选条件，取这四个字段，翻完所有页，自己挑月份是这个月的行。

- 「本店设置」里没有「「预算」表」这一行：写「设置里缺「预算」表，这次没出」，停下。
- 搜索报错说表不存在：照技能正文「一、读预算」第 6 条回复。别的报错：写「预算表没取到」和报错原文，不出差额。
- 「月份」读出来是毫秒时间戳（老板把它建成了日期字段）：按本店时区换成日期，取它的年和月。
- 回复里说「第 N 行」时，用这一行的月份、类别、币种指出是哪一行，飞书没有行号。

## 类别选项

用 `…__bitable_fields_list` 读「费用」表的字段，取「类别」字段的选项。预算表的类别不在这些选项里，就是「类别对不上」。

## 「费用」表

搜「日期」在这个月 1 日到截至日之间的记录，带 `automatic_fields`，取：编号、日期、金额、币种、类别、单据类型、状态。

- 日期条件接口不认：改成按「状态」分三次搜（等于「已记」「待确认」「作废」），取回后自己按日期挑。
- 「日期」读出来是毫秒时间戳：按本店时区换成日期再比。
- 日期空着的记录，用创建时间（就是记账时间）判断在不在这段时间里；用日期条件搜时搜不到它们，所以要找没有日期的记录，按「状态」等于「已记」「待确认」再各搜一次，只挑「日期」空着、创建时间在这段时间里的。
