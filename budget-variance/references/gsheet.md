# Google 表格：预算差异怎么读

「本店设置」里：「连接」是 Google 连接的名字，「表格」是表格文件的 ID。「预算」页和「费用」页都在这一个文件里。

## 工具

只用 `…__sheets_get_values`，前缀是连接名。你没有写的工具。

## 「预算」页

老板自己建、自己填，专员只读。第 1 行是表头，从第 2 行起一行一个预算：

A 月份｜B 类别｜C 币种｜D 预算金额

读 `'预算'!A1:D300`。

- 报错说找不到这一页（例如 `Unable to parse range`）：就是没有「预算」页，照技能正文「一、读预算」第 6 条回复。别的报错：写「预算页没取到」和报错原文，不出差额。
- A 列读出来是五位数字（例如 46235）：月份那一格被设成了日期却显示成数字。不要自己换算，那一行写「第 N 行月份看不懂（请把 A 列设成纯文本，写成 2026-08）」。读出来是 `2026-08-01` 这样的日期，按它的年和月认。
- 回复里说「第 N 行」，N 是表格里的行号（表头是第 1 行）。

## 类别选项

读 `'设置'!E2:E40`，一格一个类别，空格不算。预算页的类别不在这里面，就是「类别对不上」。

## 「费用」页

列：A 编号｜B 记账时间｜C 日期｜D 商家｜E 金额｜F 币种｜G GST｜H 类别｜I 单据类型｜J 发票号｜K 到期日｜L 付款状态｜M 已付金额｜N 付款日期｜O 状态｜P 备注｜Q 原件

第 1 行是表头，第 2 行是示例行，记录从第 3 行开始。编号是写在 A 列的固定数字，不等于行号：说「第 N 条」只看 A 列。

1. 先读 `'设置'!B3:B4` 拿到记录数 n，再读 `'费用'!A3`。最后一行是 n + 2。
2. A3 是数字，而 B3 是 0 或 B4 不大于 A3：台账的公式是旧写法、坏了。实际支出写「没取到（台账的公式要修，请对 NyxBot 说：修一下台账公式）」，不出差额。
3. 从最后一行往前分段读 `'费用'!A{起}:Q{止}`，每段不超过 200 行，读到 B 记账时间早于这个月 1 日为止。从中挑出 C 日期在这个月 1 日到截至日之间的行。日期空着的行，看 B 记账时间。
4. 用到的列：A 编号、B 记账时间、C 日期、E 金额、F 币种、H 类别、I 单据类型、O 状态。
5. C 列读出来是五位数字：这一页的日期格式没设。实际支出写「没取到（费用页的日期格式没设，请找 NyxBot 修）」，不自己换算。
6. 读出来有 `#REF!`、`#N/A`、`#ERROR!`：实际支出写「没取到（表格公式坏了，请找 NyxBot 修）」。

不用「核对」页的类别合计：它只算收据和发票，不减贷项通知单和退款，还把待确认的算了进去，口径和这份技能不一样。

为什么按记账时间读到月初为止：单据常常晚几天才记，记账时间比单据日期晚；记账时间早于月初的行，日期不会落在这个月里。这个办法假定表没排过序。读到的 A 列编号不是从上往下变大的，说明有人排过序或手动插过行，可能漏行：回复末尾加一句「费用页排过序或插过行，实际支出可能不全，请在表里核一下」。
