# cake-shop-onboarding-en

> Cake shop, bakery, dessert shop, custom cake, birthday cake, cake order, inquiry, quote, order management, onboarding. Use on owner turns when a cake, dessert or bakery shop owner wants a NyxBot agent that answers customer questions and takes cake orders or custom-cake inquiries, even if the owner already has another specialist; ask whether it is the same shop or a new one. Bind this skill to NyxBot with set_agent_skills before running it. Collects the shop profile, product catalog (photo, PDF, text or website) and order rules (lead time, daily limit, custom quotes, deposit, delivery, allergen note, report times); builds a Drive folder, shop-info doc and order sheet in the owner's Google Workspace; creates a customer-facing specialist with a fixed Role that answers from the sheet and takes orders, and an owner-only order manager bound to a private copy of cake-order-desk-en with scheduled patrol reports. Never used on customer turns; never deletes or overwrites owner files.
