# restaurant-reservation-desk-en

> Restaurant reservation desk: seated, left, table turnover, move table, walk-in, seating, reschedule, cancel, pending, special requests, occasion, table status, free tables, room calendar, check-in, check-out, settings. Owner-side daily operations for a restaurant reservation specialist set up by restaurant-reservation-onboarding-en. Use only on owner turns (NyxID app, or channel messages marked (owner)) when the owner or staff says a table was seated or left (for example B3 seated, B3 left), a walk-in party sat down, a booking moved table, a guest did not show, a booking was rescheduled or cancelled, a pending booking is approved or declined, asks for bookings, live table status or free tables for a date, or changes a house rule in the Settings tab. Reads and updates the reservation Google Sheet and keeps the room calendar in step; never deletes rows; never used on customer turns.
