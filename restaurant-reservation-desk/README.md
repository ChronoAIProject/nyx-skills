# restaurant-reservation-desk

> 餐厅 订位 入座 离店 翻台 换桌 散客 排位 改期 取消 待确认 特殊要求 场合 桌况 余量 包间日历 restaurant table check-in check-out walk-in reservation desk settings. Owner-side daily operations for a restaurant reservation specialist set up by restaurant-reservation-onboarding. Use only on owner turns (NyxID app, or channel messages marked (owner)) when the owner or staff says a table was seated or left (for example B3 入座, B3 离店), a walk-in party sat down, a booking moved table, a guest did not show, a booking was rescheduled or cancelled, a pending booking is approved or declined, asks bookings, live table status or remaining tables for a date, or changes a house rule in the 餐厅设置 tab. Reads and updates the reservation Google Sheet and keeps the private-room calendar in step; never deletes rows; never used on customer turns.
