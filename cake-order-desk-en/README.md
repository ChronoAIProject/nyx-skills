# cake-order-desk-en

> Cake shop, bakery, dessert shop order desk: orders, quote, deposit, production, pickup, delivery, cancel, reschedule, patrol, morning report, evening report, needs you. Owner-side order management for a cake or dessert shop set up by cake-shop-onboarding-en. Use only on owner turns (NyxID app, channel messages marked (owner), or scheduled runs) when the owner quotes a custom order, confirms or cancels an order, records a deposit, marks an order in production, ready, picked up or delivered, reschedules, asks about orders or deliveries for a date, or when a schedule asks for an order patrol, a morning report or an evening report; then reads the Order Book and sends a structured report of new orders, orders needing the owner, upcoming deliveries and capacity. Reads and updates the shop's order Google Sheet; never deletes rows; never used on customer turns.
