# 飞书多维表格：怎么读写

「本店设置」里：「连接」是飞书机器人连接的名字，「表格」是多维表格的标识，「费用」表是数据表的 ID。

## 工具

只用这五个，前缀是连接名：`…__bitable_fields_list`、`…__bitable_records_search`、`…__bitable_record_create_with_attachments`、`…__bitable_record_create`、`…__bitable_record_update`。

- 搜索一律带筛选条件，用 `field_names` 只取要用的字段；有下一页就用 `page_token` 翻完。
- 单选字段用「等于」筛。日期条件接口不认时，改成只按别的条件筛，取回后自己按日期挑。
- 日期字段按工具要求的格式写；要毫秒时间戳时，用本店时区当天 00:00。
- 「编号」是自动编号，只读不写。回复里的「第 N 条」就是它。

## 读可选值

用 `…__bitable_fields_list` 读「费用」表的字段，「类别」「币种」两个单选字段里已有的选项就是可选值。一轮里读一次就够。

## 查重要读什么

1. 有发票号：搜「发票号」包含这串号码里最长那段数字的记录。
2. 搜「金额」等于这张单据金额的记录，取回后只看最近 60 天的。
3. 这张是正式发票：再搜「备注」包含「形式发票」的记录。

每次搜索只取：编号、商家、日期、金额、发票号、单据类型、付款状态、状态、备注。

## 新增一行

用 `…__bitable_record_create_with_attachments` 一次写入各字段，「收据」字段附上原件。

附件传不上时，不重复调用同一个写入。先搜一次，看这一行有没有写进去：

- 没写进去：用 `…__bitable_record_create` 写一次，不带附件；
- 已经写进去：不再写；
- 两种情况都在回复里写「附件没传上，原图还在聊天里」。

带附件的写入只在老板本人直接发来的消息里可用。从别的群或频道转来的消息传不了附件，照上面的办法处理。

## 读回一行

照「找一行」按编号找到这一行，取全部要核对的字段。

## 找一行

**按编号**：搜「编号」等于 N 的记录。按编号筛不了时，按老板说的商家、发票号或金额搜回来，再挑出编号是 N 的那一条。找不到就说「找不到第 N 条」。

**按商家或发票号**：搜「商家」或「发票号」包含那段文字的记录。找到几条就列出几条让老板选。

改之前都要把这一行的编号、商家、日期、金额回读给老板确认。

## 改一行

先照「找一行」找到这一行，拿到它的记录标识，再用 `…__bitable_record_update` 只传要改的字段。没传的字段不会变。

**一行只调用一次**：要改的几个字段连同「备注」放在同一次调用里，不要先改付款那几项、再单独补备注。「备注」传的是「原来的备注 + 新追加的一句」，原来的话一个字不删。一句话要改两行的，每行各调用一次。

改完读回。

## 读一个月

按「日期」落在该月搜，搜索时带 `automatic_fields`，每行的创建时间就是记账时间。翻完所有页。取的字段里要有「收据」，资料包靠它判断哪几笔没有原件。

另外两次搜索，也带 `automatic_fields`，只留创建时间在该月的：

- 补记的旧单据：「日期」在该月 1 日之前 180 天内的记录（入账自检不收更早的日期）。日期条件接口不认、搜不了：资料包那一节写「飞书这边没查补记的旧单据」。
- 没有日期的：「日期」为空的记录。

「月底应付」另搜两次：单据类型是「发票」或「贷项通知单」、付款状态是「未付」「部分已付」「不清楚」的行；付款日期晚于该月最后一天的发票。两次取回后都自己去掉单据日期晚于该月最后一天的、状态是「作废」的。

## 资料包里照写的几句

- 核对（结尾）：飞书这边没有现成的合计，合计是你一行一行加出来的。写：「合计请和表格视图底部的汇总行核对一次。」
- 原件：「原图在每一行的「收据」字段里，下载后才能打开。」再列「收据」字段是空的编号，写「这几笔的原图只在聊天记录里，请找出来一起交」。
- 明细太多、不逐行列时：「明细 N 笔，聊天里放不下。请在多维表格里按「日期」筛出 M 月，导出成 Excel，和这份资料包一起交给会计。」

## 原件

原件存在这一行的「收据」字段里。存不进去时原图只留在聊天记录里，回复里要说。
