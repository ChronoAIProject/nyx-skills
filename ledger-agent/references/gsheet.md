# Google 表格：怎么读写

「本店设置」里：「连接」是 Google 连接的名字，「表格」是表格文件的 ID。所有工作表都在这一个文件里。

## 工具

只用这三个，前缀是连接名：`…__sheets_get_values`、`…__sheets_append_values`、`…__sheets_update_values`。不建表、不清空、不删行，不用别的工具。

## 表长什么样

「费用」页：第 1 行是表头，第 2 行是示例行，记录从第 3 行开始。

| 列 | 内容 | 谁写 |
|---|---|---|
| A 编号 | 固定的数字，新增时取自「设置」页 B4 | 你，只在新增时写一次，之后不改 |
| B 记账时间 | `yyyy-mm-dd HH:mm`，本店时区的现在 | 你 |
| C 日期 | 单据日期，`yyyy-mm-dd` | 你 |
| D 商家 | 文字 | 你 |
| E 金额、G GST、M 已付金额 | 数字，不带币种符号和千分位 | 你 |
| F 币种、H 类别 | 只能用「设置」页里列出的选项 | 你 |
| I 单据类型 | 收据、发票、贷项通知单、退款 | 你 |
| J 发票号 | 文字 | 你 |
| K 到期日、N 付款日期 | `yyyy-mm-dd` | 你 |
| L 付款状态 | 已付、未付、部分已付、不清楚 | 你 |
| O 状态 | 已记、待确认、作废 | 你 |
| P 备注 | 文字 | 你 |
| Q 原件 | 「未存档」，或老板自己贴的网盘链接 | 你只写「未存档」 |
| R 未付金额、S 算出的到期日、T 距到期天数 | 公式算的 | 不写 |

**编号不等于行号。** 新记录总是插在最后一条下面，所以没人动过表的话，第 N 条在第 N + 2 行；老板排过序、删过行、插过空行就不一定。所以动任何一行之前，都要照「找一行」按 A 列找，不按行号硬改。

其他页：「设置」（B2 默认账期天数，B3 记录数，B4 下一个编号，E 列类别选项，F 列币种选项）、「待付」「近期已付」「核对」（都是公式算的，只读）、「固定支出」（老板自己填）。记录数是 A 列里编号的个数，下一个编号是最大的编号加 1，都由表格公式算。

## 先看「设置」页的数对不对

每张单据查重之前，读 `'设置'!B3:B4`（记录数 n、下一个编号）和 `'费用'!A3`。

- B3、B4 都是数字，A3 是空的或小于 B4：正常，往下做。
- A3 是数字，而 B3 是 0 或 B4 不大于 A3；或者 B3、B4 不是数字：「设置」页的公式坏了（0.6 及更早建的台账，追加新行后公式被挪开，会把编号算重）。这张不记，不查重，回复老板：「这张没记上：台账的编号公式要修。请对 NyxBot 说：修一下台账公式。修好后把这张再发给我。」

## 写的规矩

- 写入方式一律用 `USER_ENTERED`。
- **文字前面一律加一个英文单引号**（商家、发票号、备注、原件）。不加的话，「0012」会变成 12，以等号开头的内容会被当成公式执行。数字和日期不加。
- 单据类型和付款状态一定要写下拉里的字，不留空：留空的行进不了「待付」。
- 写时间前先用时间工具查本店时区的现在。
- R 到 T 列永远不写，写了会把公式挡住。
- 不排序、不删行、不插行。

## 读可选值

读 `'设置'!E2:F40`：E 列是类别，F 列是币种。一轮里读一次就够。

## 查重要读什么

用上一节读到的记录数 n，最后一行是 n + 2。这里没有按条件搜索，只能读回来自己比。

1. **有发票号**：分段读整列 `'费用'!J3:J{n+2}`，每段不超过 500 行，找归一后相同的发票号。找到了，再读那一行的 `A:P` 核对商家。这一步要读到底：很早以前付清的发票再发来一次，只有这样才查得到。
2. **金额相同**：读最后 300 行的 `'费用'!A{起}:Q{n+2}`（起 = n + 2 − 299，不小于 3），只看最近 60 天的。
3. **还没付清的发票和形式发票**：读 `'待付'!A2:T500`。更早的、还没付清的发票都在这里；备注里有「形式发票或订金」的也在这里找。

## 新增一行

1. 用「先看设置页的数对不对」读到的 B4 作为编号。
2. 用 `…__sheets_append_values` 追加到 `'费用'!A:Q`，`insertDataOption` 用 `INSERT_ROWS`：新行插在最后一条记录下面。一行 17 个值，顺序是 A 到 Q：编号、记账时间、日期、商家、金额、币种、GST、类别、单据类型、发票号、到期日、付款状态、已付金额、付款日期、状态、备注、原件。没有的值传空字符串。
3. 返回结果里有写到了哪一行（`updatedRange`），照「读回一行」核对。

一轮里入几张单据，每张都重新读一次 B3:B4 和 A3，不要自己加一。读回之后再读一次 B4，应该比你刚写的编号大 1；不是的话，回复里照实说「这一条记上了，但下一个编号没跟着变，请对 NyxBot 说：修一下台账公式」。

**写入出错或结果不明时**：不重复追加。读 `'设置'!B4`：它比你刚才拿到的编号大，说明已经写进去了，读最后一行核对；它没变，说明没写进去，这时才可以再追加一次。

## 读回一行

读追加结果里那一行的 `'费用'!A{行}:T{行}`。A 列应该就是你写的编号；对不上，或者那一行离上一条记录很远，就照实告诉老板，不说已记，请他找 NyxBot 看一下「费用」页下面有没有零散的字。

## 找一行

**按编号**：先读 `'费用'!A{N+2}:T{N+2}`。A 列等于 N，就是它。不等于 N（表被排过序或删过行）：分段读整列 `'费用'!A3:A{n+2}`，每段不超过 500 行，找到 A 等于 N 的那一行再读整行。找不到就说「表里找不到第 N 条」。

**按商家或发票号**：先在 `'待付'!A2:T500` 里找（要记付款的多半在这里）；没有再读最后 300 行的 `'费用'!A:Q` 找。找到几条就列出几条让老板选。

不管怎么找到的，改之前都要把这一行的编号、商家、日期、金额回读给老板确认，这是技能正文里「回读并问一次」那一步，不能省。

## 改一行

**一行只写一次。** 每写一次，老板都要点一张确认卡、批一条审批；付款那几格和备注分两次写，他就要点四次。所以同一行要改的格子连同备注，放进同一次 `…__sheets_update_values`，不要先写付款那几格、再单独补备注。

1. 老板回「是」之后、写之前，照「找一行」再读一次这一行的 `A:T`。A 列还是那个编号，商家、金额、付款状态和问老板时念的一样，才往下写；不一样就不写，照实说这一行变了，重新问。下面说的「原值」都取自这一次读到的，不凭记忆。
2. 定范围：从要改的最左一格到 P（备注），一段连续的格子。A、B 两列不改，Q 到 T 不写。
   - 记付款（付款状态、已付金额、付款日期、备注）：`'费用'!L{行}:P{行}`，5 个值，顺序是 L 付款状态、M 已付金额、N 付款日期、O 状态、P 备注。
   - 作废（状态、备注）：`'费用'!O{行}:P{行}`，2 个值。
   - 其他单项按上面的列表找列，例如改到期日是 `'费用'!K{行}:P{行}`，改金额是 `'费用'!E{行}:P{行}`。
   - 改金额而已付金额要跟着改的（技能「三」的表里第一种）：范围还是 `'费用'!E{行}:P{行}`，E 和 M 写新金额，其余夹在中间的格子照原值写回。
3. 填值。范围里有几格就传几个值，一格都不能少：
   - 要改的格子写新值。
   - **备注（P）**写「原来的备注 + 新追加的一句」：原来的备注整段照抄，一个字不删、不改写，新的一句接在后面；原来是空的，只写新的一句。
   - **夹在中间、不用改的格子写回原值**，一个字不变。记付款时夹着的是 O（状态）：原来是「待确认」就写「待确认」，不改成「已记」，也不留空，留空会把这一格清掉。原来就是空的格子传空字符串。
   - 写回原值也照「写的规矩」：发票号这类文字前面加英文单引号，数字不带千分位，日期写 `yyyy-mm-dd`。
4. 只调用这一次。出错或结果不明：不再调用，先读这一行，看改没改上，照实说。
5. 改完读回这一行的 `A:T`：A 列还是原来的编号，要改的格子是新值，备注里原来的话都在，其余格子和第 1 步读到的一样，才算改好。有一格对不上，照实告诉老板是哪一格、原来是什么、现在是什么，不说已改好。

一句话要改两行（两条都记已付、贷项抵发票）：每行各写一次，写完一行、读回，再写下一行。

## 读一个月

1. 读 `'设置'!B3` 拿到记录数。
2. 从最后一行往前分段读 `'费用'!A:Q`，每段不超过 200 行，读到记账时间早于该月 1 日为止（该月的单据不可能在这之前记）。从中挑出三种行：日期落在该月、状态不是「作废」的；记账时间在该月、日期早于该月的（补记的旧单据）；记账时间在该月、日期空着的。
3. 读 `'核对'!A1:N400`：左边一块是每年每月、每个币种、每种单据类型的金额合计、GST 合计和笔数；右边一块是每年每月、每个币种、每个类别的金额合计和笔数（只含收据和发票）。取该月的行。**资料包里的合计用「核对」页的数。** 你自己加出来的和它不一样时，以它为准，并写明「逐行相加和表格合计不一致，差多少」。
   先比笔数：左边一块该月各行的笔数加起来，应该等于第 2 步挑出的、日期落在该月的行数。少了，多半是老板给「费用」排过序，往前读提前停了：改为从第 3 行起分段读整张「费用」页（每段不超过 200 行），重新挑一次第 2 步的三种行。还对不上，照出，在「要你定的事」里写差几笔。
4. 「月底应付」两处相加，两处都去掉状态（O 列）是「作废」的：
   - `'待付'!A2:T500` 里单据类型是发票、单据日期不晚于该月最后一天的（到现在还没付清，付款状态「不清楚」的也在这里）；同一页里单据类型是贷项通知单、单据日期不晚于该月最后一天的，就是还没抵的贷项；
   - `'近期已付'!A2:T500` 里单据日期不晚于该月最后一天、付款日期晚于该月最后一天的（月底时还没付清，之后才付）。这一页的公式不排除作废，要你自己去掉。
   「近期已付」只有最近 120 天内付的发票。出更早月份的资料包时，在这一项后面写「只含最近 120 天内付款的发票」。

没有日期的记录不属于任何一个月，不进资料包；它们会留在「待确认」里。

## 资料包里照写的几句

- 核对（结尾）：「合计取自表格的「核对」页，由表格公式算出。」和你逐行加的一致时，后面加「和逐行相加一致」。
- 原件：「原图不在表里。」后面写 Q 列贴了链接的是第几条；Q 列还是「未存档」的，请老板从网盘「原件」文件夹按编号找出来一起交。
- 明细太多、不逐行列时：「明细 N 笔，聊天里放不下。请把「费用」页下载成 Excel（文件 → 下载），和这份资料包一起交给会计，请会计按「日期」筛出 M 月。」

## 原件

**这套存储存不了聊天里的原图。** 新增时 Q 列写「未存档」。

- 每次入账的回复末尾加一句：「原图没有存档，请自己存进网盘的「原件」文件夹，文件名写上第 N 条。」同一轮里入了几张，只在最后说一次。
- 老板把链接贴进 Q 列之后，这一行就算有原件。
- 月底资料包里「没有附件」那一项，列的是 Q 列还是「未存档」的行。

## 应收：表长什么样（店里装了应收专员才有）

「应收」页在同一个表格文件里，只有你写，应收专员只读。第 1 行是表头，第 2 行是示例行，记录从第 3 行开始。

A 流水号｜B 发票号｜C 单据类型｜D 开票日期｜E 客户｜F 内容｜G 币种｜H 不含税金额｜I 税额｜J 金额｜K 到期日｜L 收款状态｜M 已收金额｜N 收款日期｜O 状态｜P 关联发票号｜Q 来源｜R 备注｜S 记账时间｜T 未收金额｜U 距到期天数

- A 流水号：本表起草的发票和贷项通知单都有；外部已开的发票，转来的话里给了才填，否则空。
- B 发票号全表唯一，认一张发票只看它，不按行号。A、B 只在新增时写一次，之后不改。
- C 单据类型：发票、贷项通知单。L 收款状态：未收、部分已收、已收、不清楚。O 状态：已开、待确认、作废。Q 来源：本表起草、外部已开。这四列写下拉里的字。
- J 是总额；未登记 GST 时 H 等于 J、I 是 0。
- T、U 是公式，永远不写。「待收」页也是公式，只读。

「设置」页：B6 发票起始流水号、B7 下一个发票流水号、B8 下一个贷项流水号、B9 应收记录数、B10 贷项起始流水号，B7 到 B9 是公式，你只读，不改。

## 应收：先看设置页

读 `'设置'!A6:B9`。A6 到 A9 依次是「发票起始流水号」「下一个发票流水号」「下一个贷项流水号」「应收记录数」，B7、B8、B9 都是数字：有应收表，往下做。不是这样：照 `references/receivables.md`「先看能不能写」回，不写。

## 应收：下一个流水号

发票读 `'设置'!B7`，贷项通知单读 `'设置'!B8`。不要自己数、自己加一。一轮里记几张，每张都重新读。

## 应收：查发票号

1. 读 `'设置'!B9` 拿到记录数 m，最后一行是 m + 2。
2. 分段读整列 `'应收'!B3:B{m+2}`，每段不超过 500 行。比之前先归一：只留字母和数字，字母转大写（INV-0003、inv 0003 算同一个）。这一步要读到底。
3. 找到了，再读那一行的 `'应收'!A{行}:U{行}`。

## 应收：新增一行

1. 用 `…__sheets_append_values` 追加到 `'应收'!A:S`，`insertDataOption` 用 `INSERT_ROWS`，`USER_ENTERED`。一行 19 个值，顺序是 A 到 S：流水号、发票号、单据类型、开票日期、客户、内容、币种、不含税金额、税额、金额、到期日、收款状态、已收金额、收款日期、状态、关联发票号、来源、备注、记账时间。没有的值传空字符串。
2. 发票号、客户、内容、关联发票号、备注前面加英文单引号；数字不带千分位；日期写 `yyyy-mm-dd`，记账时间写本店时区的现在 `yyyy-mm-dd HH:mm`。
3. 读回 `updatedRange` 那一行的 `'应收'!A{行}:U{行}`：B 列是你写的发票号，客户、金额、到期日对得上。本表起草的，再读一次 B7（贷项读 B8），应该比你用的流水号大 1；不是的话照实说「这张记上了，但下一个号没跟着变，请对 NyxBot 说：检查应收表的编号公式」。

写入出错或结果不明：不重复追加。照「应收：查发票号」看这个号在不在、客户和金额对不对；在，就读回，不再写；不在，才可以再追加一次。

## 应收：找一张

按发票号：照「应收：查发票号」在「应收」的 B 列找到那一行。只说了客户或金额的：可以先在 `'待收'!A2:U500` 里找出对得上的几张让老板选，选定后照样回到「应收」的 B 列找那一行。**「待收」页的行号和「应收」不是一回事，写的时候只用「应收」的行号。**

## 应收：改一行

和「改一行」一样，**一行只写一次**，写之前先读：

1. 老板回「是」之后、写之前，再读一次这一行的 `'应收'!A{行}:S{行}`。B 列还是那个发票号，客户、金额、收款状态和问老板时念的一样，才往下写；不一样就不写，重新问。
2. 定范围：从要改的最左一格到 R（备注），一段连续的格子。A、B 不改，S 到 U 不写。
   - 记已收（收款状态、已收金额、收款日期、备注）：`'应收'!L{行}:R{行}`，7 个值：L、M、N 写新值，O 状态、P 关联发票号、Q 来源照原值写回，R 写备注。
   - 贷项抵原发票：同一段 `'应收'!L{行}:R{行}`，L、M 写新值，N 收款日期照原值写回（冲掉的不是收到的钱，不填也不清掉），O、P、Q 照原值，R 写备注。
   - 作废（状态、备注）：`'应收'!O{行}:R{行}`，4 个值，P、Q 照原值写回。
   - 改到期日：`'应收'!K{行}:R{行}`。补全「待确认」的：`'应收'!D{行}:R{行}`，O 改成「已开」。
   - 只加一句备注：`'应收'!R{行}`。
3. 范围里有几格就传几个值，一格不能少。备注写「原来的备注 + 新追加的一句」；夹在中间不改的格子照原值写回，原来空的传空字符串。文字照样加单引号。
4. 只调用这一次。出错或结果不明：不再调用，先读这一行，看改没改上，照实说。
5. 改完读回这一行，B 列还是那个发票号，要改的是新值，其余和第 1 步一样，才算改好。

贷项通知单要写两处：先新增贷项那一行、读回，再改原发票那一行、读回。
