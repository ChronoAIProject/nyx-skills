# Seat assignment rules

Follow these rules whenever the reservation specialist assigns a table type to a guest, or the owner asks to move a table or seat walk-ins. A short version of the rules is already in the fixed Role template (see `role-snippet.md`), because guest turns cannot read skills. Whether a large room may go to a small party, and which bookings the owner reviews first, come from Settings.

## Every table type has a party range

Each row in Tables has "Min guests" and "Max guests". A party can only go to a table type where `Min guests ≤ party size ≤ Max guests`.

| Table type | Default range (if the owner says nothing) |
|---|---|
| 2-seat | 1–2 |
| 4-seat | 1–4 |
| 6-seat round | 4–6 |
| 8-seat round | 6–8 |
| Room | The owner's range, for example Small room 6–8, Large room 10–15 |

Small hall tables have a minimum of 1; the "just right" rule in step 3 prevents waste. The minimums on rooms and large round tables stop small parties from taking up large spaces.

## Assignment order

1. **Pin down the party size first.** If the guest gives a range ("6 to 8 people", "about 10"), ask for the exact number. If the guest is unsure, ask "Shall we plan for 8?" and record the number the guest agrees to. Do not round up or down on your own and then confirm.
2. **Hall or room.** If the party size fits both a hall table type and a room range (for example 6–8 guests), ask the guest whether they want the hall or a room, together with any other missing details. If the guest has no preference, seat them in the hall.
3. **Pick the table type that is just right.** Among the table types whose range fits, pick the one with the smallest Max guests that still has space in the area the guest asked for (hall or room).
4. **If the wanted table type is full, offer the guest choices in this order, one or two options at a time:**
   1. Another suitable table type in the same session and area (for example, 6 guests want a room, Small room is full: an 8-seat round table in the hall);
   2. The same table type in a nearby time slot (for example an hour earlier or later, or switching to Lunch or Dinner);
   3. Another date.
5. **Do not assign a table type above the party's range.** If the party is smaller than a table type's Min guests, do not assign that table type, even if it is free. Only when Large room for small parties in Settings says "Yes: …" (for example "Yes: minimum spend S$500") may you offer it, after the guest has turned down the step 4 options, and you must state the condition clearly.
6. **If it differs from what the guest asked for, ask before confirming.** If the assigned table type, area, party size or session differs from the guest's own words in any way, explain it in one sentence and ask whether the guest accepts. Record it as "Confirmed" and send the confirmation only after the guest agrees. If the guest does not reply, do not record it.
7. **Seating preferences.** If the guest mentions a preference such as "quiet", "by the window" or "spacious", pick the first free table for that day, session and table type in Lookup whose bracketed tags contain that word. Match similar wording by meaning ("not near the door" means avoid tables tagged door). If none match, assign as usual and tell the guest "We'll do our best to arrange that"; make no promise. Write the preference in the Special requests column.
8. **Assign a table number.** With no preference, take the first free table for that day, session and table type in Lookup, write it in Bookings column C, and tell the guest in the confirmation (for example "P01 Small room"). Front of house may move the table; after a move, the restaurant tells the guest.
9. **Record what was actually assigned.** The "Table type" column holds the table type actually assigned. If it differs from what the guest first asked for, write in the "Notes" column: "Guest asked for: Small room; agreed to an 8-seat round table in the hall".

## Examples

- 6 guests want a room and a Small room is free: assign the Small room and confirm directly.
- 6 guests want a room, both Small rooms are full, and an 8-seat round table in the hall is free: "The small rooms are fully booked for this time. We can give you an 8-seat round table in the hall, or a small room at 13:30. Which would you prefer?" Confirm after the guest chooses.
- 6 guests want a room, Small rooms are full and 8-seat round tables are full too: offer a nearby time slot or another date. Do not mention the Large room (unless the owner allows it).
- "6 to 8 people": first ask "How many will there be in the end? Shall we plan for 8?"
- 12 guests: only a Large room fits. If Large rooms are full, offer a nearby time slot, or ask whether they can split into two tables (two 6-seat round tables in the hall), and explain they cannot sit in the same room.
