# 本店私有订单管家技能

公开的 `cake-order-desk` 是所有店共用的模板。每家店在 Ornn 上有一份自己的私有副本，订单管家绑定的是这份副本。店里的规矩加在副本里，公开模板升级时不会覆盖它。

## 1. 建副本（建订单管家时做）

1. 用 `search_agent_skills` 找到 `cake-order-desk`，记下最新版本号 X.Y，读出 SKILL.md 全文。
2. 只改这几处：
   - `name`：店名拼音或英文 + `-order-desk`，全小写，连字符分隔，例如 `frosting-cottage-order-desk`。
   - `description` 开头加「{店名}专用（基于公开模板 cake-order-desk X.Y，加本店规矩）。」，后面照抄。NyxBot 的建技能工具描述上限 400 字符：超了只留开头这句和中文关键词（订单 报价 订金 制作 取货 送货 取消 改期 巡查 报告）。
   - `version` 改为 `"1.0"`。
   - 标题改为「# {店名}：订单管家」，标题下加一段：
     ```
     这是{店名}的私有技能，从公开模板 cake-order-desk X.Y 复制而来，只有店主账号能看到。本店规矩写在「本店规矩」一节，和模板冲突时以本店规矩为准。

     模板来源：cake-order-desk X.Y
     ```
   - 在「## 操作」之前加「## 本店规矩」，老板没提就写「（暂无，老板说要加时写在这里）」。
3. 打包上传（Ornn `POST /api/v1/skills`，zip，目录名和 `name` 一致），或用 NyxID 自带的私有发布工具。读回确认 `isPrivate` 为真，回复老板时写出来。
4. `set_agent_skills` 把私有技能绑到订单管家，不再绑公开模板。

## 2. 老板要加店内规矩

老板说「定制款一律收 50% 订金再开工」「周六送货要加 S$5」之类：读私有技能当前正文，在「本店规矩」加一条（只影响某个操作的，在那个操作里加「按本店规矩第 N 条」），发布新版本，改绑，读回仍是私有，回老板一句加了哪条、新版本号。能用「店铺设置」表达的规矩（提前天数、订金、送货费），优先改「店铺设置」，不写进技能。

## 3. 公开模板升级时合并

老板问「订单管家有更新吗」时：读私有技能里的「模板来源」，查公开模板最新版本。一样就回「已是最新」。不一样，说明新版改了什么，问要不要合并；老板同意后，拿新模板全文按第 1 节重做，把旧副本的「本店规矩」整节和各操作里的引用原样搬过去，「模板来源」改成新版本，发布并改绑。不同意就不动。

版本号以发布工具实际返回的为准，不事先承诺具体版本号。
