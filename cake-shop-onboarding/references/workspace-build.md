# 在 Google Workspace 里建文件

两套坐标：`sheets_get_values` 和 `sheets_update_values` 用 A1 写法（`'订单'!A1`）；`sheets_batch_update_spreadsheet` 用数字 `sheetId` 和从 0 开始、末端不含的行列索引。颜色用 0 到 1 的 `red`、`green`、`blue`。

## 1. 文件夹

先查同名文件夹（`name = '{店名} 店铺管理' and mimeType = 'application/vnd.google-apps.folder' and trashed = false`）。有就停下来问老板复用还是另建。没有就 `drive_create_file` 建 `{店名} 店铺管理`，`mimeType` 为 `application/vnd.google-apps.folder`。

## 2. 店铺信息文档

`drive_create_file` 建 `{店名} 店铺信息`（`application/vnd.google-apps.document`，`parents` 为文件夹 ID），再用 `docs_batch_update_document` 写入。结构：

- TITLE：`{店名} 店铺信息`
- HEADING_1「基本信息」：店名、地址、电话或 WhatsApp、官网或社媒、营业时间、取货时间、休息日、信息更新日期。
- HEADING_1「下单规矩」：提前天数、每日接单上限、定制流程、订金和付款方式、送货区域和运费、过敏说明、改单和取消规则。只写老板确认过的。
- HEADING_1「关联文件」：订单登记表（加链接）、文件夹名。

## 3. 订单登记表

`drive_create_file` 建 `{店名} 订单登记表`（spreadsheet，`parents` 为文件夹 ID）。所有工作表都在这一个文件里，顾客专员和订单管家只认这一个表格 ID。

### 3.1 结构（一个 batch）

- `updateSheetProperties`：sheetId 0 改名 `订单`，冻结 1 行。
- `addSheet`：sheetId 1 `产品`，冻结 1 行。
- `addSheet`：sheetId 2 `店铺设置`，冻结 1 行。
- `addSheet`：sheetId 3 `速查`，冻结 2 行。
- `addSheet`：sheetId 4 `使用说明`。
- `addSheet`：sheetId 5 `常见问题`，冻结 1 行。
- `updateSpreadsheetProperties`：`timeZone` 为老板时区（新加坡 `Asia/Singapore`），`locale` 为 `zh_CN`，`fields` 为 `timeZone,locale`。

### 3.2 订单（sheetId 0）

`sheets_update_values` 到 `'订单'!A1`（`USER_ENTERED`），表头 A 到 V：

`订单号, 下单时间, 交付日期, 交付时间, 方式, 送货地址, 称呼, 电话, 类型, 产品, 规格, 口味, 数量, 写字内容, 定制说明, 过敏与饮食, 金额, 订金, 订金状态, 状态, 来源, 备注`

A2 写 `=ARRAYFORMULA(IF(B2:B="","",ROW(B2:B)-1))`：订单号等于行号减 1，追加行时 A 列传 `null`，从不写入。

各列取值：

| 列 | 内容 |
|---|---|
| B 下单时间 | `yyyy-mm-dd HH:mm`，店铺时区的现在 |
| C 交付日期、D 交付时间 | `yyyy-mm-dd`、`HH:mm`；自提是取货时间，送货是送达时段的开始 |
| E 方式 | `自提` 或 `送货` |
| I 类型 | `标准` 或 `定制` |
| Q 金额、R 订金 | 数字；定制款报价前留空 |
| S 订金状态 | `未收`、`已收`、`免收` |
| T 状态 | `待报价`、`待顾客确认`、`待确认`、`已确认`、`制作中`、`待取货`、`已送出`、`已完成`、`已取消` |
| U 来源 | 实际渠道（Telegram、WhatsApp、NyxID、电话、到店） |
| V 备注 | 顾客要求、改期记录、取消原因等，追加不覆盖 |

格式（一个 batch）：表头深蓝底（0.122, 0.22, 0.392）白字粗体自动换行；B 列 `DATE_TIME` `yyyy-mm-dd HH:mm`，C 列 `DATE` `yyyy-mm-dd`，D 列 `TIME` `HH:mm`，H 列 `TEXT`，Q、R 列 `$#,##0.00`（范围第 2 到 3000 行）；`setDataValidation`（第 2 到 3000 行，`showCustomUi: true`）：E、I、S、T、U 按上表做下拉；条件格式：T 为 `待报价`、`待顾客确认`、`待确认` 整行浅黄底 (1, 0.95, 0.75)，`已取消` 整行灰字 (0.6, 0.6, 0.6)；列宽默认 100，产品 160，定制说明、备注 260。

### 3.3 产品（sheetId 1）

表头 A 到 K：`编号, 分类, 品名, 规格 / 尺寸, 价格, 类型, 提前天数, 口味选项, 备注, 简介, 份量`。按 `catalog-transcription.md` 一款一行。J 简介写口感和主要用料，K 份量写几人份；资料里没有就留空，不编。F 类型只写 `标准` 或 `定制`；G 提前天数是数字，空表示按「店铺设置」的默认提前天数。

### 3.4 店铺设置（sheetId 2）

店铺事实和规矩都在这里，老板以后改规矩只改 B 列。`sheets_update_values` 到 `'店铺设置'!A1`，`valueInputOption` 用 `RAW`（时间范围和数字不能被当成日期或公式），行的顺序照下表：

| 行 | A 设置项 | B 值 | C 值为空时的默认 | D 说明 |
|---|---|---|---|---|
| 2 | 店名 | {店名} | | |
| 3 | 地址 | {取货地址} | | |
| 4 | 电话 | {电话或 WhatsApp} | | |
| 5 | 时区 | {时区} | Asia/Singapore | |
| 6 | 营业时间 | {如 周二至周日 10:00–20:00} | | |
| 7 | 取货时间 | {如 11:00–19:00} | 同营业时间 | 自提只接这个范围 |
| 8 | 休息日 | {如 周一；没有写「无」} | 无 | 写星期几，多个用「、」 |
| 9 | 标准款提前天数 | {如 1} | 1 | 交付日期至少比今天晚几天；产品表 G 列有值时以产品为准 |
| 10 | 定制款提前天数 | {如 3} | 3 | |
| 11 | 每日最多接单 | {数字，或「不限」} | 不限 | 按交付日期计，已取消不算 |
| 12 | 定制款先报价 | {是/否} | 是 | 是：定制款登记为待报价，店主报价后顾客确认 |
| 13 | 订金 | {如 定制款 50%，标准款全款；或 不收} | 不收 | |
| 14 | 付款方式 | {如 PayNow 9xxx xxxx} | 店主另行通知 | 告诉顾客怎么付，不在对话里收款 |
| 15 | 送货 | {是/否} | 否 | |
| 16 | 送货区域与运费 | {如 全岛 S$15，满 S$100 免运费} | | 送货为否时留空 |
| 17 | 送货时段 | {如 11:00–13:00、15:00–18:00} | | |
| 18 | 问过敏 | {是/否} | 是 | 是：必填齐后问一句过敏或饮食要求 |
| 19 | 过敏说明 | {如 厨房使用坚果、麸质、乳制品，无法保证无交叉污染} | 请顾客向门店确认 | 专员只按这句回答，不作保证 |
| 20 | 改单取消规则 | {如 交付前 48 小时可改期，订金不退} | 请顾客联系门店 | |
| 21 | 待确认类别 | {如 10 寸以上；或 无} | 无 | 除定制款外，还要店主先过目的订单 |
| 22 | 巡查时间 | {如 每天 09:00、18:00} | 每天 09:00、18:00 | 订单管家定时巡查的时间 |
| 23 | 上次巡查时间 | （留空） | | 订单管家每次巡查后写入，不要手改 |
| 24 | 官网 | {官网或社媒链接} | | |

格式：表头深蓝白字粗体，B 列浅黄底 (1, 0.97, 0.8) 表示可改，A 列宽 140、B 列 420、C 列 220、D 列 360，B、D 列自动换行。

### 3.5 速查（sheetId 3）

专员读这里：第 1 行把店铺设置压成一格，第 3 行起每天一行、未来 60 天，按交付日期统计已接单数。

先写第 1 到 3 行（`USER_ENTERED`）：

```
A1  设置
B1  =TEXTJOIN("；",TRUE,ARRAYFORMULA(IF('店铺设置'!A2:A40="","",'店铺设置'!A2:A40&"="&IF('店铺设置'!B2:B40="",'店铺设置'!C2:C40,'店铺设置'!B2:B40))))
A2  日期    B2  星期    C2  已接单    D2  剩余名额    E2  其中定制
A3  =TODAY()
B3  =TEXT(A3,"dddd")
C3  =SUMPRODUCT((TEXT('订单'!$C$2:$C$3000,"yyyy-mm-dd")=TEXT($A3,"yyyy-mm-dd"))*('订单'!$T$2:$T$3000<>"已取消")*('订单'!$T$2:$T$3000<>""))
D3  =IFERROR(VALUE(REGEXEXTRACT($B$1,"每日最多接单=(\d+)"))-C3,"不限")
E3  =SUMPRODUCT((TEXT('订单'!$C$2:$C$3000,"yyyy-mm-dd")=TEXT($A3,"yyyy-mm-dd"))*('订单'!$T$2:$T$3000<>"已取消")*('订单'!$T$2:$T$3000<>"")*('订单'!$I$2:$I$3000="定制"))
A4  =A3+1
```

日期两边都用 `TEXT(…,"yyyy-mm-dd")` 比，订单里偶尔按文字写入的日期也能对上。然后一个 batch 两次 `copyPaste`（`PASTE_FORMULA`）：A4 复制到 A5:A62；B3:E3 复制到 B4:E62。第 n 行是今天之后 n−3 天。格式：A 列 `DATE` `yyyy-mm-dd`，第 2 行深蓝白字粗体，B1 灰字不换行。

### 3.6 常见问题（sheetId 5）

顾客专员回答产品以外的问题靠这张表。表头 A 到 E：`问题, 回答, 来源, 提问时间, 状态`。

- 接入时按第一步 B 组收集的内容写入，C 来源写「官网」或「店主」，D 留空，E 写「已答」。至少覆盖：保存方式和能放多久、各尺寸几人份（产品表 K 列已有的不重复）、能否少糖或做无麸质、是否清真、送不送蜡烛餐具和生日牌、包装、送货注意事项、能否开发票或收据。老板没给答案的问题不写。
- 顾客问到表里没有答案的问题时，顾客专员追加一行：A 问题原话，B 空，C「顾客提问」，D 时间（`yyyy-mm-dd HH:mm`），E「待回答」。订单管家巡查时列出，店主回答后写进 B 列、E 改为「已答」，以后同类问题直接用。
- 格式：表头深蓝白字粗体，A 列宽 260，B 列宽 480，自动换行；E 为「待回答」的行浅黄底。

### 3.7 使用说明（sheetId 4）

一列文字一行一条：六个工作表的分工；常见问题表里的回答顾客专员会照着说，店主可以直接补充或修改；改规矩只改「店铺设置」B 列，下一单生效；「速查」和订单号是公式不要手改；订单状态的含义和流转（待报价 → 待顾客确认 → 已确认 → 制作中 → 待取货或已送出 → 已完成）；老板对订单管家说的几句话；巡查报告什么时候来。A 列宽 900，自动换行。

## 4. 核对清单

- 读 `'订单'!A1:V2`：表头 22 列，A2 是公式。
- 读 `'产品'!A1:K` 首尾各三行，行数和整理时一致。
- 读 `'常见问题'!A1:E`：接入时收集的问答都在，状态「已答」。
- 读 `'店铺设置'!A1:D24`：23 项都在，B 列和老板的回答一致。
- 读 `'速查'!A1:E4`：B1 是一串「项=值」，A3 是今天，C3 是 0，D3 是每日上限或「不限」，没有 `#NAME?`、`#ERROR!`。
- `docs_get_document`：一个 TITLE，三个 HEADING_1。

## 5. 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| `Unable to parse range` | 工作表名不对或还没建 | 先跑 3.1 |
| 设置里「11:00–19:00」变成小数 | 用了 `USER_ENTERED` | 3.4 改用 `RAW` |
| 速查某天已接单数不对 | 订单状态拼错，或交付日期写成了别的格式 | 状态用下拉；日期写 `yyyy-mm-dd` |
| 订单号是空的 | A2 的数组公式被覆盖 | 重写 A2，追加时 A 列传 `null` |
