# 方法：从人物志到 60 秒片子

## 观众是谁
观众只有一个人：**这位老板本人**。他不懂技术，英文可能不行，很忙。
片子要让他在 60 秒内觉得三件事：
- "这说的就是我"；
- "我被坑了好久"；
- "这个东西现在就能帮我，还不要钱"。

用"您"称呼他，语气像自己人跟他掏心窝子，不像广告。

## 素材表（先填，再写）
| 项 | 从哪里找 | Forest Media 的例子 |
|---|---|---|
| 骄傲 | 人物志的作品、朋友圈、门面 | 8 张他自己做的招牌照片 |
| 真实痛点 | 人物志的"卡住他的"、方案页的"今天的情况" | 英文单要绕业务员、分介绍费；客户存的是业务员的号码 |
| 他的原话 | 人物志的引用 | 「每个招牌都不一样」 |
| 现在已开通 | 用户说的或方案的 | 听电话、做官网 |
| 下一步 | 用户说的 | 信息回复（不点名 WhatsApp） |
| 他要拍板的事 | 人物志的"要他点头的" | 价格、做法、日期 |
| 条款 | 方案的价格段 | 试用三个月 · 不要钱 · 不签合同 |
| 不能说 | 人物志的"不要" | AI、API、自动报价、承诺 WhatsApp |
| 口号 | 方案的主标题 | 招牌您来做。英文交给它。 |

## 故事结构（约 62 秒，按 120 BPM 排）
| 段 | 时长 | 做什么 | 情绪 |
|---|---|---|---|
| 1 骄傲 | 3–4s | 他自己的作品照片按拍子一张张弹出；"这些……都是您的得意之作。" | 点头 |
| 2 憋屈 | 14–16s | 3–4 个小节拍，每拍一句、一个画面，把痛点讲具体。最后一句大字砸下来（"太憋屈了！"），画面雾化 | 往下沉 |
| 3 转折 | 2–4s | "现在，不一样了。" → 闪白高潮："英文电话，它来接。" | 抬头 |
| 4 演示 | 7–8s | 来电：英文逐词出字，下面配中文小字；NyxBot 收集信息、**不报价**，用他的原话 | 好奇 |
| 5 结果 | 9–10s | 他手机上的中文卡片，"等您一句：价格 / 做法 / 日期"；他语音说一句 → NyxBot 用英文回过去；大字点题（"这一单，客人是您自己的！"） | 扬眉吐气 |
| 6 第二个服务 | 7–8s | 闪白高潮："客人上网，找不到您？""说一句话。" → 网站一块块搭出来，放他自己的作品照片 | 惊喜 |
| 7 预告 | 3–4s | "下一步 · 信息回复 · 即将开通" | 期待 |
| 8 收尾 | 7–8s | 出场顺序固定：① NyxID × 客户标志 → ② 口号上句 → ③ 口号下句 → ④ 三个条款标签依次弹出 | 定心 |

结构原则：
- **一个画面只讲一件事。** 每个镜头一句大字，最多再配一张卡片。
- **首尾呼应。** 开头的词在后面再用一次，例如开头"得意之作"、官网段"放的全是您的得意之作"；开头"憋屈"、结果段"客人是您自己的！"。
- **高潮落在关键词上。** 闪白和重音的时间就是那个词说出来的时间。
- 总长控制在 45–65 秒。用户嫌长就砍段落，不要压语速。

## 配音写法
- 中文约**每秒 4 个字**，不超过 4.6；一个英文单词按 2 个字算。
- 每句 2–5 秒；句间至少空 0.3 秒，段落之间空 0.5–0.8 秒。
- 口语，短句，多用逗号断气；不要书面语，不要形容词堆砌。
- 用他的原话。例子：「每个招牌都不一样，您说了算。」
- 每句给一个**语气提示**，例如"往下沉""扬眉吐气""一项一顿"。
- 用户给了现成的开头：一字不改，按逗号拆成几句，每句配一个画面节拍。

## 演示段的写法（通话）
- 客人 2 句、NyxBot 2 句，英文要短。
- NyxBot 那句要体现规矩，例如 "Every sign is custom, so Boss Bai will price it himself."
- 英文逐词出现；说完后才淡入中文小字，不然观众没空读英文。
- 声波颜色区分说话人：绿色是客人，紫色是 NyxBot。
- 挂断后切到他手机的中文卡片，上面只有中文和需要他拍板的东西。

## 迭代记录（Forest Media 这条片子走过的路）
1. **v1 90 秒、9 段**：用户说"太长太复杂，不够激动人心"。
2. **v2 36 秒**：只讲两项服务，加信息回复预告，无配音。
3. **v3 49 秒**：按中文配音的语速重新排节奏，交付配音稿和字幕。
4. 结尾出场顺序被指定为：标志 → 口号上句 → 口号下句 → 标签。
5. **v4 51 秒**：按人物志重写痛点（业务员、介绍费），用他的作品照片。
6. **v5 62 秒**：用户给了开头文案，拆成 5 拍；后面整段平移 10.8 秒。

**经验：先短后长。用户给方向，你给节奏。**
