# 设计：NyxID 浅色画布

画布 1920×1080，30 fps，浅色主题（客户方案页指定 light only）。
结构靠描边和留白，**紫色只给 NyxBot**，客户品牌色只给客户。

## 色板（CSS 变量，已写在 film.html 的 :root 里）
| 用途 | 变量 | 值 |
|---|---|---|
| 背景 | `--bg` | #F4F4F5 |
| 卡片 | `--card` | #FFFFFF，描边 `--line` #DCDCE1 |
| 正文 | `--fg` / `--mute` / `--tert` | #18181B / #3F3F46 / #5B5B63 |
| NyxBot 紫 | `--nyx` | #5E00F5；渐变 `--vivid` #A672FB→#5E00F5（大字用 `.grad`） |
| 紫底 | `--nyx-bg` | rgba(94,0,245,.07) |
| 成功 / 警告 / 错误 | `--ok` `--warn` `--err` | #059669 / #B45309 / #DC2626 |
| 客户品牌色 | `--fm` | Forest Media 红 #D7262E、墨 #1F2733。**换客户时改这一组** |
| 客人气泡 | `--cust-bg` | #E4F5D0（浅绿） |
| 老板气泡 | `--boss-bg` | #F0ECFF（浅紫） |

颜色语义要固定，观众靠颜色认人：
- 红：客户自己、痛点里的"损失"；
- 橙（`--warn`）：中间人，例如业务员；
- 绿：客人、成功；
- 紫：NyxBot、"交给它"。

## 字体（`assets/fonts`，全部是 OFL 授权）
- **中文：** Noto Sans CJK SC，打包的是 GB2312 子集，有 Regular、Medium、Bold、Black 四个字重。系统已装同名字体时优先用系统的。
- **西文 UI：** Mona Sans 400–800。
- **数字、时间、号码：** JetBrains Mono。

## 字号（1080p 画面上，手机上也要看得清）
| 元素 | 字号 / 字重 |
|---|---|
| 高潮大字 | 190–250px / 800–900，可用 `.grad` 渐变 |
| 口号 | 136–150px / 800 |
| 段落大字 | 76–92px / 700–800 |
| 卡片标题 | 52–58px / 700 |
| 卡片正文 | 30–40px |
| 标签 | 30–36px |
| 小注、页脚 | ≥ 19px |

**正文不要小于 24px。**

## 版式
- **安全边距：** 左右 ≥ 96px，上下 ≥ 72px。右下角固定放"演示 · …为示例"标签（`#tag`）。
- **大字镜头：** 水平居中（`.kin` 类，left:0 width:1920 居中），上下分两行。
- **演示镜头：** 左边手机（520×860，圆角 56），右边转写或卡片（宽约 1040，left 760）。
- **背景：** 一团慢慢移动的紫色光晕（`#glow`）加几条斜细线（`#lines`），高潮时跟着跳。
- **闪白：** 只在 2–3 个高潮上用，不超过 0.16 秒。
- **卡通人物：** 用 `p-boss`、`p-sales` 两个符号，扁平头像放在白色圆形里。不要用真人照片当人物。
- **客户照片：** 白底卡片，圆角 20，带一行说明。原图小的话控制在约 330px 宽，并加一点轻微旋转让它像拍立得。

## 动效语言
- **入场：** 淡入、轻微上移、去模糊，0.3–0.45 秒，ease-out。
- **大字：** 从放大 1.45 倍缩回 1，加去模糊，0.3 秒，有冲击感。
- **卡片和标签：** 带一点回弹（back-out）。
- **退场：** 每个场景结束前 0.35 秒整体淡出加模糊，场景之间不要硬切。
- **情绪最低点：** 雾化（白色半透明遮罩）、人物变灰、大字抖动 0.5 秒。
- **节拍：** 120 BPM，一拍 0.5 秒。弹出、闪白尽量落在拍点上；对不上的话以配音的关键词为准。
